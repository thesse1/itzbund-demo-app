<img width="412" height="343" alt="image" src="https://github.com/user-attachments/assets/a7ee6ff4-b6f1-4e41-8865-92bddcbd0595" />

Das Template erzeugt die Ausgagsbasis für eine einfache Node.js Anwendung. [initial commit](https://github.com/thesse1/itzbund-demo-app/commit/1a5c98ba0539a8a0582ed2f4092c3ac2754d7fdd) von dem Backstage Scaffolder.

Der Eintrag in Backstage kann direkt [hier](https://github.com/thesse1/itzbund-demo-app/blob/main/catalog-info.yaml) im Repository gepflegt werden:

```
apiVersion: backstage.io/v1alpha1
kind: Component
metadata:
  name: "itzbund-demo-app"
spec:
  type: service
  owner: user:guest
  lifecycle: experimental
```
